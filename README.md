# TrackPoint Courier

A small, dependency-free TrackPoint training game. Built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or server is required.

## Deploy to GitHub Pages

1. Create a new GitHub repository (for example, `trackpoint-courier`).
2. Add `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the Pages URL to appear in the Pages settings.

Every game asset is inline; there are no dependencies, API calls, or build tools.

## Game modes

- Warm-up: large targets for basic pointer control.
- Precision: smaller targets for fine movement.
- Courier route: numbered targets in sequence.
- Package delivery: pointer drag-and-drop practice.

The game measures pointer interaction, not the physical device. Use the TrackPoint and its physical buttons during practice for the intended training effect.
