# TrackPoint Courier — Courier Club

A dependency-free TrackPoint training arcade built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step, server, or install is required.

## Play

Grab falling parcels and drop them in the catch box. Scroll over the bottom rail to move the box across its limited range. Each parcel adds its printed value to your score; a missed delivery costs that value from the contract buffer. The shift ends when the buffer reaches zero.

Choose an all-round circuit or focus on precision, tracking, and route changes. Keyboard players can focus the playfield, use the arrow keys to move the box, and press Enter on a parcel to deliver it.

The game measures pointer interaction, not the physical device. Use the TrackPoint and its physical buttons during practice for the intended training effect.

## Deploy to GitHub Pages

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.
4. Wait for the Pages URL to appear in the Pages settings.
