# TrackPoint Courier

A small, dependency-free TrackPoint training game. Built with plain HTML, CSS and JavaScript.

## Play

Open `index.html` in a modern browser. No build step or server is required.

Packages fall from the top of the screen. Catch each one before it hits the ground by moving a delivery box underneath it — or grab a package directly and drag it in yourself. Every catch adds to your score and streak; drops reset your streak but never end the run.

## Controls

- **Scroll** (left/right) to steer the delivery box — the core TrackPoint movement.
- **Click and hold a package, then drag it** straight into the box — the core TrackPoint click-and-drag.
- Arrow keys move the box as a keyboard fallback.
- Both controls work together or on their own, so you can mix steering and dragging mid-run.

## Endless progression

There are no rounds or a completion screen. Catches raise your score and streak, and each stage spawns packages faster, drops them quicker, and shrinks the box. Occasional gold packages are worth 3x points. Pause and resume anytime without losing your run.

## Deploy to GitHub Pages

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.
4. Wait for the Pages URL to appear in the Pages settings.

Every game asset is inline; there are no dependencies, API calls, or build tools.

## TrackPoint technique

Keep your hands in typing position. Use your index finger on the red cap for steering and clicking. Use your thumbs for the physical buttons when dragging a package into the box.
